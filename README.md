
#### 2. Aktifkan GitHub Pages (kalau ini website statis)
- Masuk ke **Settings** → **Pages**
- Pilih branch `main` dan folder `/root`
- Nanti dapat link: `https://username-anda.github.io/ujianon/`

#### 3. Kelola Issue (buat to-do list)
- Tab **Issues** → **New issue** → buat catatan fitur yang mau dikerjakan

#### 4. Invite Kolaborator (kalau mau kerja tim)
- **Settings** → **Collaborators** → tambahkan username teman
